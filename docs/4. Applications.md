### yay

Instructions taken from https://github.com/jguer/yay

```bash
sudo pacman -S --needed git base-devel
git clone https://aur.archlinux.org/yay.git
cd yay
makepkg -si
``` 

Cleanup
```bash
cd ..
sudo rm -r yay
```

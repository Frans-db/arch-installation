# Hyprland

One of my main goals with my Arch installation is to get Hyprland completely customized to my liking.

## Installation

Install the `hyprland` package, `kitty` for the terminal, and `noto-fonts` so you can read. `ttf-jetbrains-mono-nerd` will come in handy later

```bash
sudo pacman -S hyprland kitty noto-fonts ttf-jetbrains-mono-nerd
```

Second, we install some basic utilities. A browser (`firefox`) and a filemanager (`nautilus`). I also immediately install `gvfs-smb` to allow for connections to smb shares

# Arch Installation Guide

This is my personal Arch installation guide. This guide is in no way a replacement for the arch wiki, instead it is my own

## Live Environment

### Root

#### Wifi

If you know the wifi network you are trying to connect to you can immediately connect using:

```bash
iwctl
station wlan0 connect `SSID`
```

If not you may need to use `scan` and `get-networks`

```bash
iwctl
station wlan0 scan
station wlan0 get-networks
station wlan0 connect `SSID`
```

Finally, exit `iwctl` and check your internet connecting:

```bash
ip link
ping ping.archlinux.org
```

#### Partitioning

Find the name of the disk you want to partition

```bash
fdisk -l
```

Start partitioning:

```bash
fdisk /dev/nvme0n1
```

With the partitions created and formatted we can mount them

```bash
mount /dev/nvme0n1p2 /mnt
mount --mkdir /dev/nvme0n1p1 /mnt/boot
```

#### Configuring the System

To create a usable system we must install some essential packages. What these are will depend on your system. For me they are:

**Firmware**: `base linux linux-firmware intel-ucode`
**Boot Loader**: `grub efibootmgr`
**Network**: `networkmanager`
**Tools**: `vim sudo`

```bash
pacstrap -K /mnt base linux linux-firmware intel-ucode grub efibootmgr networkmanager vim sudo
```

```bash
genfstab -U /mnt >> /mnt/etc/fstab
```


### Chroot

Change root (`chroot`) into the installation by running:

```bash
arch-chroot -S /mnt
```

#### Time & Localization

Setting the timezone will ofcourse depend on your own timezone, for me `Europe/Amsterdam` is correct

```bash
ln -sf /usr/share/zoneinfo/Europe/Amsterdam /etc/localtime
hwclock --systohc
```

Up next we want to set the correct localization. To do this edit `/etc/locale.gen` and uoncomment the UTF-8 locales you will be using. For me this is `en_US.UTF-8 UTF-8`. Then run

```bash
locale-gen
```

Finally, edit `/etc/locale.conf` and add `LANG=en_US.UTF-8` (or the locale you chose)

```bash
vim /etc/locale.conf
# LANG=en_US.UTF-8
```

To make our machine recognizable on the network we set a hostname. For this I usually use the manufacturer name for the device. In my case this is a `Dell Precision 5560` so as a hostname I use `precision5560`

```bash
vim /etc/hostname
# precision5560
```

#### Boot Loader

I use `GRUB` for my bootloader.

```bash
grub-install --target=x86_64-efi --efi-directory=/boot --bootloader-id=GRUB
grub-mkconfig -o /boot/grub/grub.cfg
```

#### User & Root Account

Personally I immediately disable the root account and rely on a user account (with `sudo` access) for everything. 

Lock the root account:

```bash
passwd root -l
```

Create a new user. Mine is called `fdeboer`

```bash
useradd -m -G wheel fdeboer
passwd fdeboer
```

Finally, we need to actually enable the usage of `sudo` for the `wheel` group:

```bash
EDITOR=vim visudo
# uncomment
# # %wheel ALL=(ALL:ALL) ALL
```

#### Reboot

After this we are ready to reboot the system into Arch Linux:

```bash
exit
reboot
```
